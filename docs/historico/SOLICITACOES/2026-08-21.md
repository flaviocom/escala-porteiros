**Aprendizado:** perguntar "você já está operando assim?" antes de aceitar uma especificação
detalhada é o movimento certo — a resposta era "parcialmente": a estrutura (diário raiz + rotação
por período + índice) já existia sob outro nome (`DIARIO_DE_BORDO.md`), mas o formato granular por

registro no calor da hora, outra para o porquê mais profundo — a própria skill já previa essa
divisão de trabalho.

**Cuidado:** não confundir os dois regimes de "histórico" deste projeto — `DIARIO_DE_BORDO.md`
(Regime B clássico, raiz, teto 2.000 linhas/virada de MÊS) e este diário de solicitações (Regime
B-especial, subpasta, teto 700 linhas/90 KB, corte por SESSÃO/DIA). São tetos diferentes de
propósito, não um erro de configuração — aplicar o teto errado a qualquer um dos dois rotacionaria
cedo ou tarde demais.
