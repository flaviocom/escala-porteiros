## A solicitação

> — `D:\Documentos\CCB_Escalas\Porteiros\escalaagosto2026.png`

Uma imagem, sem mais instrução. Ela é a especificação.

## O que a referência mostra, e o que o site fazia

A referência é um **documento**: cabeçalho azul com mês e ano, legenda dos turnos, **um cartão por
dia** com bloco colorido à esquerda (mês / dia / dia-da-semana), pílula do turno, nomes em fichas com
a inicial num círculo, tracejado separando os turnos do mesmo dia, e rodapé com a data de geração.

O site fazia outra coisa: **fotografava a tela**. Pegava o `#schedule-container`, ligava um modo
`is-exporting` que sobrescrevia largura, cores e pesos de fonte no meio da captura, e — o pior —
**fatiava a lista em 5 dias** a partir de hoje.

```ts
// ScheduleTable.tsx, antes
if (isExporting) {
  const upcomingIndex = result.findIndex(s => isSameDay(s.date, today) || isAfter(s.date, today))
  result = result.slice(startIndex, startIndex + 5)   // ← cinco dias
}
```

Numa escala de cinco meses, a imagem saía com **cinco dias**. E o `export.ts` ainda avisava
*"Tente filtrar um período menor"* quando falhava. **É por isso que existe um arquivo de referência
feito por fora**: o produto nunca conseguiu gerar aquilo.

## O que foi construído

| | |
|---|---|
| `src/export/EscalaImagem.tsx` | o layout, com **estilos em linha** — o CSS do aplicativo não o alcança |
| `src/export/gerarImagem.ts` | monta fora do campo de visão, espera as fontes, captura |
| `src/utils/export.ts` | ficou só com o que sempre foi dele: **entregar** o arquivo |
| `src/dados/filtrar.ts` | o filtro, agora **um só**, usado pela tela **e** pela imagem |

**Estilo em linha é decisão, não descuido.** Foi o acoplamento com o CSS da tela que fez a imagem
antiga envelhecer junto com o site. A imagem precisa ser a mesma em qualquer aparelho, em qualquer
versão da interface.

**O filtro virou função única.** Enquanto a imagem era uma fotografia da tela, o filtro podia morar
dentro do `ScheduleTable`. Com layout próprio, *"exportar o que está aparecendo"* passaria a exigir a
mesma regra em dois lugares — e duas cópias de uma regra é onde as duas divergem em silêncio.

**E o corte de 5 dias sumiu.** Ele existia porque a tela não aguentava a captura, não porque o
formato pedisse. O período inteiro cabe.

## Duas correções que a comparação com a referência expôs

**A legenda não explicava a cor mais chamativa.** O cartão da Santa Ceia sai em vermelho, e
`SANTA CEIA` não estava na legenda. Agora a legenda mostra **só o que existe no período** — e inclui
a Santa Ceia quando ela existe.

**A contagem inflava o número.** Dizia *"19 turnos"* somando a Santa Ceia — que é um dia **sem**
porteiros. Virou **`18 turnos · 1 Santa Ceia`**. É o tipo de número que alguém repete depois como se
fosse trabalho escalado.

## O que a imagem gerada mostra a mais que a referência

O **16/08 aparece como SANTA CEIA, sem porteiros**. A referência do Flavio é anterior à correção e
traz **seis irmãos escalados** naquele dia. A diferença é de **dado**, não de forma — e é exatamente
o defeito que este projeto veio consertar.

## 🔴 O defeito que eu criei ao tirar o corte — e que o portão pegou

Tirei o corte de 5 dias e **não gerei o período inteiro**. O portão que eu tinha acabado de escrever
foi rodado com `tudo` e devolveu:

```
  dimensoes ............. 969 x 16384
```

**Os navegadores cortam o canvas em 16384 pixels.** Para caber, o navegador **encolheu a largura de
1440 para 969** — e devolveu um PNG truncado e distorcido, **sem erro nenhum**. Eu tinha trocado uma
falha declarada (*"filtre um período menor"*) por uma **falha silenciosa**, que é sempre pior.

### A correção: uma imagem por MÊS

Não é remendo — é como a escala é usada. **O arquivo que o Flavio manda hoje é de um mês**, e uma
imagem de cinco meses teria 16 mil pixels de altura: ninguém lê isso num celular.

```
  arquivos gerados ...... 10
    escala-porteiros-2026-03-marco.png     1440 x 2728
    …
    escala-porteiros-2026-12-dezembro.png  1440 x 2720
```

Um mês selecionado → **um** arquivo, como antes. Vários meses → **um por mês**, todos entregues.

### E duas travas contra a mesma classe

1. **Antes de capturar:** se a altura passar do teto, é **erro com a razão escrita** — não imagem
   encolhida.
2. **Depois de capturar:** a largura do PNG é **conferida contra o pedido**. Quando o navegador
   encolhe, ele não avisa: devolve um arquivo com cara de bom. *Conferir o que saiu, não o que foi
   pedido.*

O portão agora mede **todos** os arquivos, não só o primeiro — um mês pode sair encolhido e os
outros não.

## 🔐 "Deixa o token embutido, eu só coloco a senha"

Pedido do Flavio, depois de escolher reusar o `GITHUB_PAT` que já tinha. **Não dá — e não por
preferência minha.**

O repositório **é público** (conferido, não presumido). Embutir o token significa:

1. ele vai no pacote JavaScript que **todo visitante baixa** — basta abrir as ferramentas do
   navegador para lê-lo;
2. o GitHub **varre repositórios públicos e revoga automaticamente** tokens que encontra. O botão
   Publicar quebraria sozinho, repetidamente;
3. e aquele token é **clássico**: alcança todos os repositórios dele, ThetaLens incluído.

Cifrar no código não salva: o texto cifrado ficaria público, e a senha viraria o único obstáculo,
atacável offline sem pressa nem tentativa limitada.

### O que ele queria mesmo — e isso dá

*"Eu só coloco a senha"* é legítimo, e o obstáculo real era outro: **o cofre é por navegador**, então
cada aparelho exigia cadastrar o token de novo.

**Cofre portátil.** No aparelho já configurado, um botão mostra o cofre **cifrado**, pronto para
copiar. Ele pode ir por mensagem, e-mail, o que for — sem a senha, é ruído. No aparelho novo, cola-se
uma vez, digita-se a mesma senha, e **dali em diante é só a senha**.

Três ganhos de uma vez: o token nunca aparece em texto claro, ninguém digita 40 caracteres num
teclado de celular, e revogar o token no GitHub continua derrubando todos os aparelhos de uma vez —
que é o comportamento desejado quando um deles se perde.

**11 testes** em `src/admin/cofre.test.ts`: ida e volta entre aparelhos; o código é inútil sem a
senha; texto qualquer recusado na hora; **código truncado não instala cofre quebrado** — senão o erro
viraria "senha incorreta" para sempre, mandando procurar no lugar errado.

### E o portão de fontes pegou algo no caminho

Os links para as pastas do GitHub introduziram o host `github.com` no código. O portão reprovou
**antes do commit**: *"1 host chamado e NÃO declarado"*. Declarado — e vale a nota: é o **único** da
lista que não busca dado. É endereço que a tela mostra, não chamada que o produto faz.

E o inventário é **gerado** a partir de uma constante no script. Editar o markdown à mão teria sido
inútil — a próxima geração o desfaria. O portão continuou vermelho até eu mexer na fonte certa.
