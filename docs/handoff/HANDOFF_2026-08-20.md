## 2. Tudo o que foi aprendido

- **Cada rodada de auditoria cega achou algo real que a rodada anterior não cobriu** — incluindo,
  na 5ª rodada, a PRÓPRIA correção da 4ª introduzindo o mesmo tipo de defeito por outra porta
  (`horaInicio === horaFim` virando "bloqueia o dia inteiro"). Não é sinal de trabalho malfeito —
  é o método funcionando: nenhuma correção foi aceita como fechada sem prova, nem quando a prova
  aponta pra correção anterior mesma.
- **Um contador de "primeira renderização" quebra sob `React.StrictMode`** — em desenvolvimento o
  React roda todo efeito de montagem duas vezes de propósito; a correção certa compara contra os
  valores capturados na montagem, não conta invocações. Esse detalhe quase escapou numa verificação
  ao vivo minha própria, no meio do dia.
- **`localStorage` é isolado por ORIGEM, não por caminho** — dois repositórios no mesmo
  `flaviocom.github.io` compartilham tudo que não for explicitamente namespaced. Achado e corrigido
  três vezes antes de fechar de verdade (cofre, rascunho, preferências).
- **Um aviso que só vive numa aba específica é um aviso que a maioria nunca vê** — o "você está
  vendo um rascunho" só aparecia dentro de "Gerar escala"; quem abre Elenco primeiro (a maioria)
  nunca via nada. Subiu para acima de toda aba.
- **Servidor confirma o que a tela não prova.** Duas vezes hoje uma alegação minha de "está
  publicado" precisou ser reconferida direto no GitHub Pages (`curl`) antes de eu confiar nela —
  uma vez porque um rascunho local escondia o publicado, outra porque `page.goto()` para a MESMA
  URL não força reload de verdade num app de hash-routing (precisa de `about:blank` no meio, ou
  `location.reload()` explícito).
- **Confirmar antes de decisão sensível, mesmo com autorização-guarda-chuva ligada.** Duas vezes
  hoje uma pergunta de 1 clique (dado real × fictício; qual repositório muda no fix de UX) evitou
  um retrabalho — o dono corrigiu minha direção na segunda ("não era pra mexer na Malha, era pra
  completar o Elenco") antes de eu publicar o errado.
