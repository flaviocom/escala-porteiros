## Como usar este arquivo

- **Solicitação nova?** Entra aqui **no ato**, com o ID seguinte, e aponta para onde foi implementada.
- **O ID é calculado sobre todas as fatias**, nunca lido da última linha — depois de uma rotação, o
  maior ID deixa de ser visível de onde se escreve.
- **Solicitação sem destino escrito é solicitação perdida.** A coluna da direita é obrigatória.
